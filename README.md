## 🌟 Características Principales

- **⚡ Generación Instantánea:** Crea contraseñas aleatorias y altamente seguras al instante.
- **⚙️ Ajuste de Longitud:** Slider interactivo e input de número para definir longitudes entre **10 y 30 caracteres**.
- **🎛️ Filtros de Caracteres:**
  - Solo Mayúsculas (`A-Z`)
  - Solo Minúsculas (`a-z`)
  - Solo Números (`0-9`)
  - Solo Símbolos (`!@#$%^&*...`)
  - Opción **"Todo"** para máxima complejidad.
- **🤖 Botón Gemini AI:** Generador con efectos animados y diseño inspirado en el asistente de Google Gemini.
- **📋 Copia Rápida al Portapapeles:** Copia con un solo clic y retroalimentación mediante toast animado.
- **🎨 Diseño Ultra Moderno:** Interfaz oscura (Dark Mode), gradientes fluidos y componentes responsivos.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** [React 18](https://react.dev/), HTML5, JavaScript (ES6+)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend / Servidor:** Node.js (Servidor HTTP nativo en `server.js`)
- **Iconos:** Tabler Icons & SVGs personalizados

## 🚀 Instalación y Uso Local

Sigue estos pasos para clonar y ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio

```bash
git clone https://github.com/FranciscoArias10/Fpasswords.git
cd Fpasswords
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Abre tu navegador en: `http://localhost:3000/`
